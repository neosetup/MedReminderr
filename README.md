# Medication Reminder (MedReminder) Android App

دو زبانه (فارسی / English) – کاملاً مطابق منطق و ظاهر دستگاه ESP32

## ویژگی‌ها
- **حالت آفلاین**: ذخیره تا ۸ دارو روی گوشی + نوتیفیکیشن دقیق + دکمه «مصرف شد»
- **حالت آنلاین**: باز کردن صفحه وب دستگاه ESP32 (http://192.168.4.1) داخل اپ
- انواع دارو: قرص / قطره / اسپری / تزریق (دقیقاً مثل فریمور)
- زبان خودکار بر اساس زبان سیستم گوشی (values + values-fa)
- آلارم دقیق با AlarmManager + بازیابی بعد از ریستارت

## نحوه ساخت و نصب
1. Android Studio را باز کنید
2. Open → پوشه MedReminderApp را انتخاب کنید
3. صبر کنید تا Gradle Sync تمام شود
4. یک گوشی یا امولاتور API 26+ انتخاب کنید و Run بزنید

یا از خط فرمان:
```
./gradlew assembleDebug
```
فایل APK در مسیر زیر ساخته می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

## مجوزهای لازم
- نوتیفیکیشن (Android 13+)
- آلارم دقیق (در تنظیمات گوشی → برنامه‌ها → یادآور دارو → آلارم و یادآور)
